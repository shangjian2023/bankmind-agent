# 安全设计文档

## 1. 权限分级实现

| 级别 | 判定 | 交互 | 覆盖操作 |
|---|---|---|---|
| 绿 | 静态映射 | 自动执行 | 余额/流水查询、账单分析（月/年）、理财推荐与持仓、风险测评、定时任务查询 |
| 黄 | 静态映射 | 确认卡片，approve 才执行 | 订阅查询/取消、生日方案、定时转账创建、AA 收款、虚拟卡(预留) |
| 红 | 静态映射 | 6 位模拟短信验证码，错 3 次熔断 | 挂失、理财申购/赎回、改密(预留) |
| 黄/红(动态) | `当日转出累计 + 本笔 > 1000` | 上述对应交互 | 智能转账 |

实现：`app/security/permissions.py::classify`，阈值在 `app/config.py`。待执行操作持久化为 `pending_actions`（含 slots、DAG、级别、状态机 pending→executed/declined/cancelled/failed），黄色不能跳过确认、红色不能跳过 MFA（`confirm` 接口对红色直接拒绝）。

**定时转账的权限一致性**：后台调度器（`app/scheduler.py`）到期执行时不做 MFA（无人机交互），因此设计为——届时若该笔会使当日转出累计超过 1000 元，任务被置为 `blocked` 并审计，提示用户手动发起转账走完整 MFA 流程；后台执行路径永远不会绕过权限体系。

## 2. 防 Prompt 注入

- 用户输入只作为**数据**进入规则引擎，不拼接进任何系统提示或代码执行路径。
- 正则黑名单（指令覆盖/角色越权/密钥窃取/特殊令牌等 10 类）命中即拒绝，写审计 `guard` 阶段，并计入可疑计数。
- 连续 3 次可疑输入 → 账户锁定 15 分钟（熔断）。

## 3. 操作审计

- 每回合生成 trace_id，全链路落库：`receive → guard → intent → slots → plan(含DAG节点与边) → permission → confirm_request/approved/declined | mfa_issue/verify → tool:*(每个节点输入输出) → done | tool_error | preflight_reject | circuit_block`。
- 查询：`GET /api/audit?user_id=&trace_id=`；Web UI 右上角实时审计侧栏。

## 4. 异常熔断

- 触发条件：连续 3 次工具级失败（如余额不足、MFA 错满 3 次）或连续 3 次注入尝试。
- 动作：锁定 15 分钟，期间所有请求返回 `locked` 并写审计 `circuit_block`。
- 成功操作清零计数。

## 5. 沙箱执行

- Agent 产生的计算表达式（账单环比、占比等）统一经 `security/sandbox.py::safe_eval`：AST 白名单仅允许算术运算、`abs/min/max/round/sum`、白名单变量；导入、属性访问、下标、推导式、三元等一律 `SandboxViolation`。
- 工具调用面收敛：编排器只能调用 `tools/registry.py` 注册过的函数，无任意代码执行路径。

## 6. 幻觉防护

- 回复文本由 `_build_reply` 模板**仅插值工具返回字段**生成，无工具结果即无数字输出。
- 所有账户/交易/订阅数据来自模拟库或工具返回，前端展示与后端审计一致可核对。

## 7. 已知风险清单（诚实披露）

| # | 风险 | 说明 | 缓解/计划 |
|---|---|---|---|
| 1 | 熔断状态为进程内存态 | 重启清零、多副本不共享 | 生产上 Redis；答辩时说明 |
| 2 | MFA 为模拟实现 | 验证码在演示环境回显 | 关闭 `DEV_SHOW_MFA_CODE`；接真实通道属赛后事项 |
| 3 | 意图为规则引擎 | 长尾表述可能 fallback 到帮助语 | 接入 LLM 抽象层后由模型分类兜底 |
| 4 | 注入黑名单非穷举 | 新型注入模式可能绕过 | 输入仅作数据 + LLM 接入后加输出侧过滤 |
| 5 | 无用户认证 | user_id 由前端选择 | 演示可接受；生产需登录态+会话绑定 |
| 6 | SQLite 单文件 | 并发写有限 | repository 层已隔离，可平滑换 Postgres |
| 7 | 演示验证码回显 | 方便演示但非安全实践 | 明确标注"演示环境模拟" |
| 8 | 理财产品年化为静态演示值 | 非真实市场数据 | 模拟环境声明；回款按本金模拟不计息 |
| 9 | 定时调度器单实例内存循环 | 多副本部署会重复执行 | 生产需分布式锁/消息队列；演示单实例 |
